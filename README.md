# Specialization Outfitter

A lightweight World of Warcraft addon that automatically changes your outfit when switching specializations.

Created by **Armir** of **Area 52**.  
Inspired by the original **Outfitter** addon by Rhenyra.

---

## Features

- Automatically applies outfits when changing specialization
- Uses Ascensions's built-in Outfit/Wardrobe system
- Supports all available specializations
- Simple and lightweight UI
- Minimal performance impact

---

## How It Works

1. Create outfits using the default Ascension wardrobe system
2. Open the addon with:

```lua
/specfit
```

3. Assign an outfit to each specialization
4. Whenever you switch specialization, the addon automatically applies the selected outfit


---

## Developer Notes

Developer mode prints debug information to chat.

Enable with:

```lua
/specfit dev
```
